# Multi-Dimensional Change Impact & Blast Radius Model

## Impact Dimensions Evaluated

Every simulated configuration change undergoes comprehensive multi-dimensional evaluation:

1. **Governance & Compliance**: Projects changes in compliance scores (`+12.5%` or `-25.0%`) and identifies newly failing or passing controls.
2. **Security Posture**: Evaluates IAM privileges, network exposure, public access blocks, and default encryption.
3. **Dependency Blast Radius**: Integrates Phase 48 topology graphs to calculate direct and downstream dependencies.
4. **Observability**: Determines telemetry metric resolution impacts.
5. **FinOps Economics**: Projects monthly billing deltas (`+$2.10/mo`).
6. **Resilience & Predictive Risk**: Projects incident probabilities (`0.05` vs `0.95`).
